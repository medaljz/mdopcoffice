# 作词

先确定用户给出的主题、叙述视角、情绪走向与风格。信息足以创作时直接完成；未指定曲式时自行选择适合主题的主歌、副歌和桥段安排。

用具体场景承载情绪，每一段推动故事或情绪，不只替换近义词重复感叹。副歌保持核心表达清晰、可记忆；押韵服务表达，不为了整齐牺牲语义或强行缩短句子。桥段引入新的认识、决定或视角，为最后一次副歌提供变化。

交付完整歌名与歌词，以清楚的段落标签区分曲式。通读检查人称、时间和意象是否连贯，删除无意义的重复。用户要求修改时保留指定内容，按反馈调整。

把最终歌词保存到当前项目目录中的 lyrics.md；创作说明可另存文件。除非任务明确要求，交付范围只包括文字，不启动音乐生成、配音、外部发布或平台写回。
